# 黄金回购批次与动态定价复核

管理黄金回购物件、检测、动态报价、付款和库存批次谱系。

## 参与方与事实

主要参与方包括回购机构、个人投资者、检测人员、定价复核人员、付款与库存人员。领域资料记录以下已经确认的事实：

- 国际金价显著上涨并带动回购需求
- 零售品牌调整金饰价格
- 贵金属价格受避险和政策预期影响

## 业务约束

- 物件身份
- 检测回执
- 锁价规则
- 付款补偿
- 熔炼批次谱系

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/gold_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
